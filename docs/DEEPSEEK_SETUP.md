按你的要求，问答改成了**深度思考模式**：

1. 你的问题直接抛给 DeepSeek；
2. 模型**先思考**（理解意图 → 检索 → 决策，思考过程约 3000+ token）；
3. 它自己在**全量 600 家店**里翻（以紧凑摘要形式注入，不是砍成 8 家）；
4. 拍板选 1 家，给出带原话的理由。

实测：问"今晚想吃点清淡的，最好能堂食，别太贵"，模型选了"糖包轻食"，理由完整展现了思考链（便宜+堂食 → 轻食不油 → 4人提口碑稳 → 无争议），并引用原话。
