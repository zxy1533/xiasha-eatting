# ADR-0003: 模型锁 deepseek-v4-flash，Key 只在云函数

- 状态：已接受（型号可换）
- 日期：2026-11-22
- 决策者：高见远（架构师）

## 背景
> 成本公式对单价最敏感（brief Q1/§5）。需要一个具体型号把 ¥0.002–0.019 的宽泛区间收敛成可预算的数字，同时前端构建产物绝不能出现 Key（AC-08/F7-e）。2026-11-22 查官方文档确定 V4-Flash 单价。

## 决策
> 我们将锁定 deepseek-v4-flash（非思考模式），经云函数用原生 https 调用；API Key 只存云开发环境变量，模型名/单价/端点全部可配置。

## 后果
- 变容易的：单次成本收敛到 ¥0.0018–0.0048（中位 ¥0.0033）；换模型只改配置不改代码。
- 变困难的：峰谷定价与汇率换算带来 ±约 50% 波动，需按峰时保守预算；深模型能力弱于旗舰，长尾问法质量需实测。
- 引出的新决策：换型号须重跑 SPEC §8 成本表并确认月度封顶数值（Q5）。

## 备选方案
| 方案 | 为什么没选 |
|---|---|
| 腾讯混元 API | mvp-stack.md 单价高于 DeepSeek 一档；本场景是短文本拍板，低价优先 |
| GPT/Claude | 单价高一个数量级，与 ¥300 封顶冲突 |
| 本地 Ollama | 需常驻硬件与运维，违背单人可维护与云开发选型 |
